# PWA LAB

React と Vite で作った、PWA のインストールとオフライン動作を試す小さなアプリです。

## 起動

Node.js と pnpm を用意し、このディレクトリで実行します。

```sh
pnpm install
pnpm build
pnpm preview
```

表示された `http://localhost:4173/` を Chrome または Edge で開いてください。通常の開発作業には `pnpm dev` も使えますが、PWA の確認にはビルド済みアプリを配信する `pnpm preview` を使用します。

## 確認手順

1. 初回表示後、「オフライン対応」が「有効」になるまで待つか、一度再読み込みします。
2. 「アプリをインストール」が有効なら押して、ブラウザーのインストール画面を確認します。インストール後は OS のアプリ一覧から開き、「表示モード」が「アプリ画面」になることを確認します。
3. 「カードを追加」を押します。ブラウザーの開発者ツールの Network で Offline を選ぶか、ネットワークを切って通常の再読み込みをします。画面とカードの数が残ることを確認します。

`beforeinstallprompt` は対応ブラウザーで、ブラウザーがインストール可能と判断したときだけ発火します。既にインストール済みの場合など、ボタンが有効にならないこともあります。その場合はブラウザーのメニューにある「インストール」や「ホーム画面に追加」を確認してください。iPhone/iPad では共有メニューからホーム画面に追加します。スマートフォンから試す場合は HTTPS で公開する必要があります（`localhost` へのアクセスは例外）。

カードの数は `localStorage` に保存されます。画面自体のオフライン表示は Service Worker のキャッシュによるものです。
